# ANIFLIX 要件メモ

## 1. 目的

観たいアニメを探し、どのくらい時間が必要かを把握して、無理のないペースで視聴を進められるようにする。

家族で使うことを想定し、プロフィールごとに視聴データを分ける。

## 2. 想定ユーザー

- 観たいアニメは多いが、どこから始めるか迷う人
- 子どもと親で観る作品を分けたい家族
- 1日の空き時間に合わせて、完走までの目安を知りたい人

## 3. ページ構成

| ページ | 役割 |
| --- | --- |
| アプリ概要 | アプリの目的と主要機能を紹介する |
| 作品を探す | AniList API でアニメを検索し、視聴中へ追加する |
| 視聴中 | 視聴進捗・残り時間・完走目安を管理する |
| Watchリスト | 視聴完了した作品を記録するライブラリ |
| プロフィール | 家族ごとのプロフィール作成・切替・編集を行う |

## 4. 機能要件

### 作品検索

- AniList GraphQL API を使用する
- 作品名、画像、話数を表示する
- 検索結果から直接「視聴中」に追加できる
- 検索失敗時はエラーを表示する

### 視聴中

- 作品ごとに見終わった話数を `−／＋` ボタンで更新できる
- 1話を24分として、残り時間を計算する
- 1日の視聴時間を30分〜10時間まで30分刻みで選べる
- 残り時間と1日の視聴時間から完走までの日数を算出する
- 最終話まで進めた作品は Watchリストへ自動で移動する

### Watchリスト

- 視聴を完了した作品を表示する
- 作品名、話数、総視聴時間、完走日を表示する

### プロフィール

- プロフィール名とアイコンを編集できる
- 家族用に複数プロフィールを作成・切替できる
- 各プロフィールで視聴中・完走履歴・視聴時間設定を分離する

## 5. 非機能要件

- PC とスマホの両方で使いやすいこと
- スマホでは固定ボトムナビを表示すること
- iPhone などのセーフエリアを考慮すること
- 操作データは Local Storage に保存し、再読み込み後も残ること
- 子どもや親も使いやすい、柔らかいダークテーマにすること

## 6. 技術構成

- Next.js 16（App Router）
- TypeScript
- Tailwind CSS
- AniList GraphQL API
- Local Storage
- Vercel（公開）
